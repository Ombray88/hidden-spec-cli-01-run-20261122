# mend

`mend` is a robust command-line tool designed for the [make.fun competition](https://make.fun/bounty/hidden-spec-cli-01-run-20261122) that parses and applies edits generated by AI models across a tree of text files using an all-or-nothing transactional guarantee.

## Supported Patch Formats
- Unified diff (`unified`)
- SEARCH/REPLACE blocks (`search-replace`)
- V4A patches (`v4a`)
- JSON tool calls (`json`)

## Usage

Run `mend` using Node 22 (standard library only):

```bash
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
```

## Example

Applying a patch file (`patch.txt`):

```bash
node main.ts patch.txt
```

Where `patch.txt` contains:

```
hello.txt
<<<<<<< SEARCH
Hello World
=======
Hello Universe
>>>>>>> REPLACE
```

Or from stdin:

```bash
node main.ts << 'EOF'
hello.txt
<<<<<<< SEARCH
Hello World
=======
Hello Universe
>>>>>>> REPLACE
EOF
```
